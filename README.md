Stone Paper Scissor

A simple Stone-Paper-Scissor game built using HTML, CSS, and JavaScript.

Features
Play against the computer.
Random computer choice generation.
Automatic winner detection.
Score tracking.
Username input.
Displays win, lose, and draw results.
Technologies Used
HTML
CSS
JavaScript
About the Project

This project was created as a frontend development practice project to improve my understanding of JavaScript and DOM manipulation.

The JavaScript game logic was written by me. The website's CSS design and styling were implemented with the assistance of AI.

Concepts Practiced
DOM manipulation
Event listeners
querySelector and querySelectorAll
JavaScript functions
Conditional statements (if-else)
Math.random()
Template literals
classList
Updating HTML elements using JavaScript
CSS Flexbox and media queries
How to Run
Clone the repository.
Open the project folder.
Open index.html in your browser.
Enter your name and start playing.
